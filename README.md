# 人才网招聘网程序人才招聘系统/招聘APP/H5/求职招聘兼职/招聘企业职位求职招聘小程序

源码地址：ym7k.com/11046/

一套成熟的本地化人才招聘系统，支持微信小程序、H5 网页端、PC 管理后台，适合搭建县城、工业园区、地级市本地人才招聘网站，全职 + 兼职一体化，工厂招工、企业直招、蓝领白领岗位全覆盖。

### 求职者端功能

- 首页入口：找工作、找兼职、招聘会、找人才、名企招聘、附近职位
- 职位筛选：按地区、岗位类别、薪资、福利筛选，支持同城附近岗位定位
- 简历管理：上传简历、投递岗位，查看投递记录、面试邀约
- 职位订阅：有匹配新岗位推送通知，不错过合适机会
- 一键申请岗位，查看岗位福利：社保、包吃住、年终奖、年假、餐补等标签展示

### 企业端功能

- 企业认证入驻，发布全职 / 兼职岗位，设置薪资、招聘人数、岗位福利、任职要求
- 管理收到的简历，查看投递记录，邀约面试
- 付费增值：岗位置顶、急聘标识、刷新过期岗位，购买 VIP 会员套餐提升曝光
- 可以自主管理发布的所有招聘信息，到期自动下架，后台可续期

### 后台管理核心模块

- 招聘信息管理：岗位查询、新增招聘、编辑删除、审核、设置置顶 / 急聘、设置到期时间
- 简历信息管理、投递记录、面试邀请记录
- 企业管理、会员套餐管理、订单管理
- 招聘会管理、举报管理、轮播图、弹窗广告、资讯分类
- 数据导出：全职招聘汇总导出、兼职招聘汇总导出
- 订阅群发、群发日志管理，批量推送招聘消息

### 核心亮点

✅ 多端互通：微信小程序 + H5 + PC 管理后台
✅ 岗位双类型：全职招工 + 兼职灵活用工，兼顾工厂蓝领和白领岗位
✅ 同城定位：附近职位，非常适合工业区、县域劳务市场
✅ 审核机制：后台审核岗位，控制平台信息质量，支持举报
✅ 盈利体系完整：企业会员套餐、置顶、急聘、岗位刷新、广告投放
✅ 招聘会模块：线上招聘会专区，适合劳务公司、人力资源公司
✅ 数据导出：批量导出岗位信息，方便线下汇总
✅ 岗位到期机制：岗位到期自动过期，支持后台续期刷新

本地人才网、县城劳务招工平台、工业园区招聘平台、人力资源公司、蓝领招工小程序、企业直招求职平台
